# Tempo Musical: Reproductor Multimedia

Un reproductor de audio e interfaz gráfica interactiva diseñado para ofrecer una experiencia fluida y moderna en la gestión y reproducción de contenido multimedia.

---

## Características

* **Controles Interactivos:** Funciones de reproducción, pausa, avance, retroceso y ajuste de volumen.
* **Interfaz de Usuario (GUI):** Diseño intuitivo centrado en la experiencia de usuario para la navegación visual.
* **Gestión de Recursos Multimedia:** Manejo de listas de reproducción, portadas de audio y recursos explicativos (`.mp4`, `.png`).
* **Sincronización en Tiempo Real:** Actualización dinámica del estado del reproductor mediante el manejo de eventos.

---

## Tecnologías utilizadas

* **Lenguajes:** HTML5, CSS3, JavaScript (ES6+).
* **Conceptos:** Programación Orientada a Objetos (POO), Manipulación del DOM, Programación Dirigida por Eventos (Event-Driven).
